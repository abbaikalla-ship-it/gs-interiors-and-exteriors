GS INTERIOR & EXTERIORS PORTFOLIO

Files:
- index.html: responsive portfolio website
- assets/gs-logo.png: supplied shop logo

Upload the contents of this folder to the root of your GitHub repository.
Then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

Important:
1. This is the first public portfolio version. The project gallery currently shows placeholders.
2. The Admin Panel with shared photo/video uploads needs a backend/database and secure admin authentication. GitHub Pages alone is static hosting; browser-only storage would not publish changes to other visitors. We will connect the admin panel in the next step.
3. The PDF button opens the browser print dialog. Choose Save as PDF. Website links remain clickable in PDF viewers that preserve hyperlinks.
4. The Subscribe prompt encourages visitors to visit the channel; YouTube does not let this website verify or enforce subscription.
